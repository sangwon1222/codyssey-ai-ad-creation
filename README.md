# codyssey-ai-ad-creation

## 1. 프로젝트 개요

본 프로젝트는 AI 도구를 활용하여 브랜드 광고 영상을 기획하고 제작하는 과제입니다.

선정 브랜드는 **CANIDAY**입니다.  
CANIDAY는 무기력하거나 번아웃을 겪는 사용자가 하루 1분의 작은 행동을 통해 일상을 다시 시작하도록 돕는 캐릭터 기반 셀프케어 앱입니다.

이번 광고는 **CANIDAY 앱 서비스의 핵심 가치를 전달하는 브랜드 광고 영상**으로 제작합니다.

광고의 중심 콘셉트는 다음과 같습니다.

> 오늘도 망한 줄 알았는데,  
> 앱 속 카니가 나를 위해 1분짜리 작은 행동을 꺼내준다.

즉, 사용자가 현실에서 무기력한 상태에 있을 때, **CANIDAY 앱 안의 캐릭터 CANI가 화면 밖으로 나와 작은 행동을 준비해주는 듯한 연출**을 사용합니다.

## 4. 브랜드 아이덴티티

### 브랜드명

CANIDAY

### 서비스 설명

CANIDAY는 사용자가 부담 없이 실행할 수 있는 아주 작은 행동을 제안하고, 캐릭터 피드백과 보상을 통해 일상 회복을 돕는 셀프케어 앱입니다.

사용자는 앱에서 오늘의 작은 행동을 확인하고, 실행 후 간단한 완료 경험을 얻습니다.  
이 과정에서 캐릭터 CANI는 사용자를 평가하거나 압박하지 않고, 작은 행동을 시작할 수 있도록 부드럽게 도와주는 역할을 합니다.

### 타겟 사용자

- 10대 후반 ~ 20대
- 해야 할 일은 많지만 시작이 어려운 사람
- 번아웃, 무기력, 불규칙한 생활 패턴을 경험하는 사람
- 자기관리 앱을 설치해봤지만 오래 지속하지 못했던 사람
- 거창한 목표보다 지금 당장 할 수 있는 작은 행동이 필요한 사람

### 톤앤매너

- 트렌디한 숏폼 감성
- 부담 없는 위로
- 귀엽지만 과하지 않은 캐릭터 연출
- 차분하고 따뜻한 색감
- “열심히 살아라”가 아니라 “1분만 해보자”에 가까운 메시지

### USP

CANIDAY는 사용자가 큰 목표를 세우도록 요구하지 않습니다.  
대신 사용자의 상태에 맞는 작은 행동을 제안하고, 이를 반복 가능한 루틴으로 연결합니다.

핵심 차별점은 다음과 같습니다.

1. 큰 목표보다 작은 실행을 먼저 제안합니다.
2. 무기력한 상태에서도 시작 가능한 행동 단위로 쪼개줍니다.
3. 캐릭터 CANI가 부담 없는 방식으로 행동을 유도합니다.
4. 기록 중심이 아니라 실행 시작 중심의 셀프케어 경험을 제공합니다.

## 6. 광고 영상 구성 방향

최종 광고 영상은 단순한 앱 기능 소개 영상이 아니라, 10대 후반과 20대가 공감할 수 있는 숏폼 광고 문법을 사용합니다.

기존의 자기계발 앱 광고처럼  
“힘들다 → 앱 알림이 온다 → 실행한다 → 좋아진다”의 뻔한 구조를 피하고,  
**앱 속 캐릭터가 현실의 작은 행동을 꺼내주는 듯한 연출**을 사용합니다.

### 광고 콘셉트

**앱 속 카니가 오늘의 1분을 꺼내준다.**

사용자는 하루를 망쳤다고 느끼지만, CANIDAY 앱 속 CANI가 조용히 등장해 물 한 잔, 10초 호흡, 짧은 정리 같은 작은 행동을 준비해줍니다.

이 광고에서 CANI는 인스타툰 세계관의 캐릭터가 아니라, **CANIDAY 앱 서비스 안에서 사용자의 행동을 도와주는 브랜드 캐릭터**로 표현됩니다.

### 스토리 구조

1. 공감 훅

   - 사용자가 침대나 책상 앞에서 아무것도 시작하지 못하는 장면으로 시작합니다.
   - 화면에는 “오늘도 망한 줄 알았다”처럼 짧고 공감 가능한 카피를 사용합니다.
   - 과장된 우울 표현은 피하고, 10대 후반~20대가 일상적으로 느끼는 무기력과 시작의 어려움을 표현합니다.

2. 앱의 등장

   - 휴대폰 화면에 CANIDAY 앱 알림이 나타납니다.
   - 알림 문구는 부담스럽지 않게 구성합니다.
   - 예: “1분만 해볼까?” / “물 한 잔부터 시작해볼까?”

3. 카니의 서비스적 개입

   - CANIDAY 앱 화면 안에서 CANI가 등장합니다.
   - CANI가 화면 밖으로 살짝 나오는 듯한 AI 영상 연출을 사용합니다.
   - 카니는 현실을 마법처럼 바꾸는 존재가 아니라, 사용자가 바로 할 수 있는 작은 행동 카드를 꺼내주는 안내자처럼 표현합니다.

4. 작은 행동 실행

   - 사용자는 물 한 잔 마시기, 10초 호흡, 책상 위 물건 하나 치우기 같은 행동을 실행합니다.
   - 화면은 급격하게 밝아지지 않고, 아주 조금 정돈되고 가벼워지는 정도로 표현합니다.
   - 메시지는 “인생이 바뀐다”가 아니라 “오늘을 다시 시작할 수 있다”에 둡니다.

5. 브랜드 각인

   - 마지막 3~5초에 CANIDAY 앱 화면, 브랜드명, 슬로건, CTA를 노출합니다.
   - 브랜드명과 앱 서비스가 명확하게 인지되도록 마무리합니다.

### 엔딩 카피

**오늘을 리셋하는 가장 작은 방법**  
**CANIDAY**

### CTA

### 예상 영상 길이

### 예상 화면 비율

## 9. 제작 파이프라인

본 프로젝트는 다음 순서로 제작합니다.

1. CANIDAY 브랜드와 캠페인 메시지를 정의합니다.
2. 앱 서비스 홍보에 맞는 광고 스토리라인을 구성합니다.
3. 씬별 스토리보드를 작성합니다.
4. 씬별 이미지 생성 프롬프트를 작성합니다.
5. 이미지 생성 AI로 키비주얼을 제작합니다.
6. 이미지-투-비디오 AI로 짧은 모션 영상을 제작합니다.
7. AI 오디오 도구로 내레이션, 효과음, 배경음악을 생성합니다.
8. CapCut에서 컷 편집, 자막 삽입, 오디오 레벨 조정을 진행합니다.
9. 최종 MP4 영상을 출력합니다.
10. 스토리보드 PDF와 최종 광고 영상을 GitHub에 정리하여 제출합니다.

## 12. 제작 전략

멀티모달 AI 제작에서는 캐릭터, 앱 화면, 영상 톤이 흔들리는 문제가 자주 발생합니다.  
이를 줄이기 위해 다음 전략을 사용합니다.

1. CANIDAY 앱 서비스 홍보 영상이라는 목적을 유지합니다.
2. 인스타툰 세계관, 테라리움 설정, 별도 캐릭터 서사는 사용하지 않습니다.
3. CANI는 CANIDAY 앱 안에서 사용자를 돕는 서비스 캐릭터로 표현합니다.
4. 이미지 생성 단계에서 씬별 구도와 앱 화면 톤을 먼저 확정합니다.
5. 캐릭터 CANI의 색상, 형태, 표정 규칙을 프롬프트에 반복적으로 명시합니다.
6. 영상 생성은 짧은 컷 단위로 나누어 진행합니다.
7. 모든 영상 컷의 색감은 따뜻하고 차분한 분위기로 통일합니다.
8. 최종 편집에서는 자막 위치, 앱 화면 노출 방식, 오디오 볼륨을 통일합니다.
9. 크레딧 부족 상황에 대비해 정지 이미지와 짧은 패닝/줌 모션을 활용합니다.
